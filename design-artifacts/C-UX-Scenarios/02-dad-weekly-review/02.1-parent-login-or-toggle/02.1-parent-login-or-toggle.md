## Overview

**Page Purpose:** 
提供简易的魔法密码校验面板，隔离儿童打卡自省区与家长复盘成长地图控制台，防止孩子误触甚至清理 LocalStorage 中积累的珍贵打卡数据。

**User Situation:** 
周末下午，爸爸陪小睿坐在沙发上准备进行这周的亲子成长复盘。爸爸拿着电脑或平板，点击了小人书底部的“魔法导师入口”，进入此密码验证页面。

**Success Criteria:**
- 校验卡片在页面中央优雅浮现，背景为高大上的夜空深邃渐变。
- 输入正确密码 `123`（或点击跳过二次确认），页面在 300ms 内平滑过渡并载入成长地图。
- 输入错误时，锁头图标轻微抖动，提示“密码不对哦，请检查魔法书底页”，延迟 500ms 后自动清空输入框，支持重新输入。

**Entry Points:**
- 双击打开本地的 `成长地图.html` 文件。
- 从 `小人书.html` 页脚“魔法导师暗门”点击切换跳转而来。

**Exit Points:**
- 输入正确密码校验通过后，加载并渲染家长成长地图控制台 (`02.2-parent-growth-map`)。
- 点击“返回小人书”按钮返回 `小人书.html`。

## Page Sections

### Section: Access Card (密码校验卡片)
**OBJECT ID:** `parent-gate-card`

- **门头图标**
  - **OBJECT ID:** `parent-gate-lock-icon`
  - **Component:** vector SVG (Padlock)
  - **Details:** 带有夜光金粉特效的圆润锁头。
- **密码显示框**
  - **OBJECT ID:** `parent-gate-input-field`
  - **Component:** password-type text box
  - **Details:** 限制长度为 3 位，输入时显示圆点。
- **数字软键盘 (Optional Numeric Keypad)**
  - **OBJECT ID:** `parent-gate-keypad`
  - **Component:** 3x4 grid buttons
  - **Details:** 0-9 数字按键及“清除(C)”键。适配平板电脑的鼠标及手指点选，按键点击时触发微缩缩放回弹效果。
- **验证并进入按钮 (CTA)**
  - **OBJECT ID:** `parent-gate-button-submit`
  - **Component:** golden linear gradient button
  - **Content:** "确认魔法指令 ➔"
  - **Behavior:**
    - 点击后，读取输入框值进行判定。
    - 默认口令为：`123` (或是预设的管理密码)。
    - 若判定通过，向 LocalStorage 写入本次 Session 授权标记（避免频繁重输），加载 `02.2-parent-growth-map`；
    - 若判定失败，播放 `shake-error` 震动，文本框爆红，并在输入框下方浮现错误提示信息：“导师口令有误，请在小人书尾页翻找噢~”。

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Default | 刚载入页面时 | 密码输入框为空，锁头闭合，验证按钮呈半透明待命状态。 | 点击软键盘输入密码，或者键盘输入。 |
| Typing | 输入至少一位数时 | 验证按钮激活点亮，输入框圆点增加。 | 同上。 |
| Error | 口令验证失败时 | 输入框红框，软键盘红色抖动，展示错误语。 | 输入框自动被清空，光标重新 Focus，支持再次录入。 |

---

## Accessibility

- **Input Autocomplete:** 设置 `autocomplete="off"`，且输入框支持直接回车键 `Enter` 提交验证。
- **ARIA Labeling:**
  - 密码输入: `aria-label="请输入三位家长口令"`
  - 确认按钮: `aria-label="提交口令以进入家长控制台"`

---

## Technical Notes

- **Access Guard (离线会话守卫)**:
  - 验证成功后，使用 `sessionStorage.setItem("growmap_parent_auth", "true")` 临时记录会话，避免在同一浏览器标签页下切换 Tab 时重复输入口令。
