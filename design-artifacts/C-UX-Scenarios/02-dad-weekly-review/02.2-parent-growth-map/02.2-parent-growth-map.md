## Overview

**Page Purpose:** 
呈现极致对称、高审美的“成功同心圆”互动 SVG 视图，读取 LocalStorage 数据渲染六维态度成长雷达图与周心情图表，为爸爸提供直观、定量的复盘依据，并辅以沟通话题抽屉。

**User Situation:** 
周末下午，爸爸通过了口令验证，在宽屏电脑上与小睿一起浏览这份成长报告。爸爸通过完美的对称图表直观掌握女儿的心境变化和态度分布。

**Success Criteria:**
- **SVG 同心圆对称性**：6个扇区呈完美的中心对称（每 60° 均匀分立，圆心、中环、外环层级清晰无重叠，极坐标计算公式写入文档以供开发）。
- **双向 Hover 联动**：鼠标 Hover 任何 SVG 扇区，右侧对应卡片高亮；反之，Hover 卡片，SVG 相应块亮起，响应时间 ≤ 100ms。
- **离线图表渲染**：无报错，百分百稳定读出本地历史打卡，并采用纯原生 Canvas 绘制雷达图和柱状图，脱离 Chart.js 等在线 CDN。
- **引导抽屉**：点击“沟通话题卡”，智能展开一句由本周打卡最少维度决定的温润话术。

**Entry Points:**
- 口令验证页 (`02.1-parent-login-or-toggle`) 验证通过。

**Exit Points:**
- 点击顶部“退出导师视角”，清除授权标记并返回 `小人书.html`。

## Page Sections

### Section: Left Rail - Symmetrical SVG & Canvas Charts (可视化数据区)
**OBJECT ID:** `parent-visual-rail`

- **成功同心圆对称 SVG (Symmetrical Concentric Circle SVG)**
  - **OBJECT ID:** `parent-visual-svg`
  - **Details:** 采用纯 HTML 内联 SVG，中心点为 (375, 375)。
  - **极坐标对称公式 (Symmetry Formula)**：
    - 6个扇区由 $i = 0$ 到 $5$ 组成，每个扇区夹角恒为 $60^\circ$ ($\frac{\pi}{3}$)。
    - 角度区间：$[\theta_i, \theta_{i+1}]$，其中 $\theta_i = i \times 60^\circ - 90^\circ$（起始从正上方 $-90^\circ$ 开始顺时针分布）。
    - 几何内圈弧半径 $R_{in1} = 95\text{px}$，$R_{out1} = 205\text{px}$ （中环态度层）；
    - 几何外圈弧半径 $R_{in2} = 205\text{px}$，$R_{out2} = 315\text{px}$ （外环行为层）。
    - 极坐标转换直角坐标公式：
      $$x = 375 + R \times \cos(\theta)$$
      $$y = 375 + R \times \sin(\theta)$$
    - 每一个扇区的路径定义通过统一的极坐标函数动态生成，保证所有扇区分隔线严丝合缝、宽度一致，文本标签完美居中分布，解决此前重叠和不对称问题。
- **六维态度打卡热度雷达图**
  - **OBJECT ID:** `parent-radar-canvas`
  - **Component:** inline HTML5 Canvas
  - **Details:** 从 LocalStorage 读取 6 种态度（积极主动、同理心、自信、自省、勇气、胸怀）的打卡频次，用浅橘色半透明填充 Canvas 多边形。
- **心情晴雨柱状图**
  - **OBJECT ID:** `parent-mood-canvas`
  - **Component:** inline HTML5 Canvas
  - **Details:** 统计本周打卡选择的 5 类表情，以柱状图排布，反映孩子一周内的情绪起伏。

**OBJECT ID:** `parent-footer-actions`

  - **OBJECT ID:** `parent-drawer-tips`
  - **Behavior:** 自动对比六种态度的雷达分值。如果本周打卡最少的是“勇气”（例如打卡次数为 0），点击按钮会滑出提示卡：“✨ 对话小锦囊：这周小睿的【勇气宝石】打卡稍微有些少哦。爸爸可以温和地问她：‘宝贝，听说小人书里嘟嘟狗需要穿上勇气跑鞋才能完成梦想，你这周有没有遇到想做又有点害怕的事情呢？告诉爸爸，我们一起穿上跑鞋！’”
- **数据备份与导出 (Data Export)**
  - **OBJECT ID:** `parent-button-export`
  - **Behavior:** 点击后将 LocalStorage 中的 `growmap_checkin_history` 数据转化为 JSON 格式文本并提供一键复制/本地下载，供跨设备备份。
- **数据清空 (Data Reset)**
  - **OBJECT ID:** `parent-button-reset`
  - **Behavior:** 点击后弹出警示确认（“确定要清除所有自省打卡数据吗？此操作不可逆哦！”），点击确认后清空本地 LocalStorage，页面数据重置。

## Technical Notes

- **Symmetrical Polar SVG Path Code Snippet** (开发基准)：
  ```javascript
  function getSectorPath(x, y, rIn, rOut, startAngle, endAngle) {
    const startRad = (startAngle * Math.PI) / 180;
    const endRad = (endAngle * Math.PI) / 180;
    const xOutStart = x + rOut * Math.cos(startRad);
    const yOutStart = y + rOut * Math.sin(startRad);
    const xOutEnd = x + rOut * Math.cos(endRad);
    const yOutEnd = y + rOut * Math.sin(endRad);
    const xInStart = x + rIn * Math.cos(startRad);
    const yInStart = y + rIn * Math.sin(startRad);
    const xInEnd = x + rIn * Math.cos(endRad);
    const yInEnd = y + rIn * Math.sin(endRad);
    
    return `M ${xInStart} ${yInStart} L ${xOutStart} ${yOutStart} A ${rOut} ${rOut} 0 0 1 ${xOutEnd} ${yOutEnd} L ${xInEnd} ${yInEnd} A ${rIn} ${rIn} 0 0 0 ${xInStart} ${yInStart} Z`;
  }
  ```
  以此公式生成的路径百分百无偏差，边缘规整。
