## Overview

**Page Purpose:** 
通过一道极简、结合嘟嘟狗故事的判断题，检验小睿对“积极主动”与“努力学习”的理解。以非说教的趣味交互，建立小女孩的答题成就感，并自然过渡到今日打卡自省。

**User Situation:** 
小睿读完了故事，点击了“挑战积极宝石”。屏幕上弹出了一个被魔法光晕包围的挑战盒子，里面有一道可爱的多选题和几只动物助手。

**Success Criteria:**
- 答对正确选项时，触发 CSS Canvas 星星撒花礼花动效，延迟 800ms 后自动显示“前往魔法瓶打卡”通道。
- 答错选项时，选项呈现红色抖动效果（`shake-error`），提供温柔的情感化错题提示，不扣分、不惩罚，保护儿童自尊。

**Entry Points:**
- 故事阅读页 (`01.2-kids-book-story`) 点击底部的“挑战积极宝石”按钮。

**Exit Points:**
- 答题成功后，点击“前往魔法瓶打卡”按钮，弹窗平滑淡出，进入每日心情与行为打卡区 (`01.4-kids-book-checkin`)。
- 点击右上角“X”关闭弹窗，返回故事页。

## Page Sections

### Section: Modal Window (挑战弹窗主体)
**OBJECT ID:** `quiz-modal`

- **关闭按钮**
  - **OBJECT ID:** `quiz-modal-button-close`
  - **Component:** icon button (X)
- **挑战引导标题**
  - **OBJECT ID:** `quiz-modal-title`
  - **Content:** "✨ 积极宝石挑战 ✨"
- **故事关联场景题干**
  - **OBJECT ID:** `quiz-modal-question`
  - **Content:** "放学回家，突然停电了没办法看最喜欢的动画片，下面哪一个是‘积极主动’的魔法卡片？"
- **选项卡片组 (Option Cards)**
  - **OBJECT ID:** `quiz-modal-options`
  - **Option A (错误心智卡片)**:
    - **OBJECT ID:** `quiz-modal-option-a`
    - **Content:** "❌ 坐在沙发上生闷气，怪爸爸今天没带我去游乐园踢球。"
    - **Interaction Feedback:** 点击后卡片背景变为淡红色，触发 `shake-error` 动画。小狗冒出气泡：“生闷气可不能变聪明哦，再找找看别的方法吧！”
  - **Option B (正确积极卡片)**:
    - **OBJECT ID:** `quiz-modal-option-b`
    - **Content:** "🎨 主动拿出画笔和纸，在窗户边画一幅‘停电的魔法城堡’，或者去帮妈妈擦桌子。"
    - **Interaction Feedback:** 点击后卡片背景变为金色，播放礼花散落。小圆露出大大的笑容：“太棒了！这就是‘积极主动’的态度，它能让我们变被动为主动！”
- **去打卡按钮 (Success Action)**
  - **OBJECT ID:** `quiz-modal-button-success`
  - **Component:** pulse animated gradient button.
  - **Content:** "帮小圆存入宝石，去打卡！ ➔"
  - **Visibility:** 初始隐藏，只有在用户成功点击 Option B 之后才平滑向上滑动显现。

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Unanswered | 首次弹出时 | 选项 card 呈现默认状态，没有红绿色彩，去打卡按钮隐藏。 | 点击 Option A 或 Option B。 |
| Error State | 点击了 Option A | Card A 抖动呈淡红色，显示警告说明气泡。 | 可以重新选择 Option B。 |
| Success State | 点击了 Option B | Card B 亮起金色边框，全屏飘落礼花特效，去打卡按钮以淡入动画在底部呈现。 | 点击“前往打卡”按钮。 |

## Accessibility

- **Voice/Screen Reader accessibility:** 
  - 为两个选项指定 `role="radio"`，并关联 `aria-checked`。
  - 正确/错误状态变化时，通过 `aria-live="polite"` 播报反馈文字。
- **Focus Trap:** 弹窗显示时，TAB 键焦点只在弹窗内的选项、关闭按钮和下一步按钮间循环，防止焦点跳到遮罩下方的页面。

---

## Technical Notes

- **Pure CSS Confetti Effect**: 
  - 本地离线环境没有网络拉取外部 Confetti.js。使用完全行内的 CSS 星星粒子扩散动画（基于 HTML 临时节点），在 Option B 点击时挂载到 DOM 并自动在 2 秒后移除，确保 100% 离线可用且文件体积小。
