## Overview

**Page Purpose:** 
以通俗易懂、温暖童趣的冒险插画故事，具象阐述李开复同心圆模型中的“积极主动”（中环态度）与“努力学习”（外环行为）。通过拟人化的故事引导小睿认知并理解这两种概念的MECE关系与良性循环。

**User Situation:** 
小睿进入了绘本第一章，阅读小圆在成长丛林里的冒险。她通过生动可爱的交互卡片阅读故事，不需要面对干瘪的大段文字。

**Success Criteria:**
- 绘本故事总字数控制在 250 字以内，排版具有透气度，每页只有 2-3 句大字号童谣体或简单句。
- 提供“迷茫小狗”点击彩蛋。点击小狗后小狗会改变表情（例如从哭脸变笑脸），并显示激励气泡，反馈时间 ≤ 150ms。

**Entry Points:**
- 封面页 (`01.1-kids-book-cover`)，点击“开始探险”。

**Exit Points:**
- 点击故事页底部的“接受宝石挑战”按钮，滑出互动答题弹窗 (`01.3-kids-book-quiz`)。
- 点击顶部“返回”按钮回到封面页 (`01.1-kids-book-cover`)。

## Layout Structure

本页采用卡片幻灯片式的分步(Step-by-Step)滑块布局。通过“上一页”和“下一页”的按钮，让孩子掌控阅读进度。

```
+------------------------------------------+
|  [ 返回封面 ]                   [ 💡 伴读 ]|
+------------------------------------------+
|                  Main                    |
|                                          |
|            /-------------\               |
|           /   故事插图    \              |
|          |   (迷茫小狗与  |              |
|           \   积极跑鞋)   /              |
|            \-------------/               |
|                                          |
|     “小狗嘟嘟坐在路边哭泣：'雨天太讨厌啦，|
|      我的风筝飞不起来，今天什么都做不成。'” |
|                                          |
|  [ 上一页 ]                 [ 下一页 (2/3) ]|
+------------------------------------------+
|          [  🌟 挑战积极宝石 (3/3时显) ]     |
+------------------------------------------+
```

## Page Sections

### Section: Header (故事页头部)
**OBJECT ID:** `story-header`

- **返回封面按钮**
  - **OBJECT ID:** `story-header-button-back`
  - **Component:** icon button (chevron-left)
- **爸爸伴读指导小抽屉**
  - **OBJECT ID:** `story-header-button-parent-tip`
  - **Component:** top-right leaf icon button.
  - **Behavior:** 点击后右侧滑出半透明毛玻璃抽屉，向爸爸展示通俗对话引导词（例如：“如果孩子觉得自己今天没学好，可以问问她：我们今天有没有像小狗一样主动撑起伞呢？”）。

### Section: Main (故事舞台区)
**OBJECT ID:** `story-main`

- **翻页滑块容器 (Carousel Container)**
  - **OBJECT ID:** `story-carousel`
  - **Step 1 (迷茫困境)**:
    - *Illustration:* 迷茫小狗坐在雷雨中抹眼泪（原生 SVG 渲染雨滴和乌云）。
    - *Text:* 小狗嘟嘟叹气：“雨下得这么大，今天没法去踢球了，真倒霉！我只能发呆啦。”
  - **Step 2 (小圆支招 - 积极主动)**:
    - *Illustration:* 小圆走过来，递给嘟嘟一双闪闪发光的“积极跑鞋”和一把小黄伞。
    - *Text:* 小圆微笑着说：“嘟嘟，虽然我们不能让雨停下（接受不可改变），但我们可以去地下室练习传球，或者在家里读一本有趣的绘本呀（主动改变能改变的）！”
  - **Step 3 (努力执行 - 努力学习)**:
    - *Illustration:* 嘟嘟穿上跑鞋在地下室快乐地踢球，头顶浮现出金色的“努力宝石”光晕。
    - *Text:* 嘟嘟明白了！它穿上积极跑鞋，在地下室流着汗努力练习。原来，只要我们积极想办法、努力去做，雨天也是成长的好日子！
- **故事操作控制组**
  - **OBJECT ID:** `story-controls`
  - **Prev Button** (`story-button-prev`) 和 **Next Button** (`story-button-next`)：控制幻灯片切换，伴有平滑的向左/向右翻页滑动效果。
  - **挑战积极宝石按钮 (CTA)**
    - **OBJECT ID:** `story-button-challenge`
    - **Component:** pulse animated button.
    - **Details:** 仅在 Carousel 滑动到 Step 3 时在页底显著浮现。点击后触发答题挑战。

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Slide 1 | 初始进入故事 | 仅显示“下一页”按钮，文字为 Step 1，小狗为哭泣状态。 | 点击下一页。点击小狗播放眼泪动画。 |

## Accessibility

- **Keyboard navigation:** 可以通过键盘左右方向键 (Left/Right Arrow) 控制 Carousel 翻页。
- **ARIA:**
  - 伴读抽屉: `aria-label="魔法伴读提示卡，点击展开或收起"`
  - 小狗插画: `aria-label="迷茫的嘟嘟狗，点击听听它的牢骚"`
  - 挑战按钮: `aria-label="挑战积极主动与努力学习的宝石关卡"`

---

## Technical Notes

- **Animations:** 
  - 跑鞋与宝石以 CSS `animation: glow-pulse 3s infinite` 渲染呼吸发光效果。
  - 翻页效果使用 CSS `transform: translateX()` 实现硬件加速，确保离线平板无卡顿。
