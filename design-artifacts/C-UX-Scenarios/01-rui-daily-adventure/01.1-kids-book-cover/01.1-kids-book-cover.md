## Overview

**Page Purpose:** 
呈现魔法绘本故事的精美封面，展示同心圆层级隐喻（诚信为圆心、态度为中环、行为为外环），通过“开始冒险”按钮引导小女孩小睿进入每日反思学习旅程。

**User Situation:** 
8岁的小睿放学回家写完作业，在房间里双击打开本地小人书，准备开启她的今日成长探险，心情放松并对成就与趣味内容充满期待。

**Success Criteria:**
- 页面渲染在 200ms 内完成，无外部依赖引起的骨架屏卡顿。
- 小睿能被绚丽的手绘感同心圆 SVG 图表吸引，点击“开始冒险”并在 300ms 过渡动画后进入故事页。

**Entry Points:**
- 本地双击 `小人书.html` 离线文件。
- 从 `成长地图.html` 的“返回小人书”链接返回。

**Exit Points:**
- 点击“开始冒险”按钮进入第一章故事页 (`01.2-kids-book-story.md`)。
- 点击页脚“魔法导师（家长）入口”切换至成长地图。

## Page Sections

### Section: Header (头部工具栏)
**OBJECT ID:** `cover-header`

- **魔法徽章快捷显示器**
  - **OBJECT ID:** `cover-header-badge-status`
  - **Component:** inline label (SVG star icon + Text)
  - **Content:** "✨ 已解锁 [X] 枚徽章" (读取 LocalStorage 自动渲染)
- **魔法导师（家长）通道按钮**
  - **OBJECT ID:** `cover-header-button-parent`
  - **Component:** text button
  - **Content:** "🔑 魔法导师"
  - **Behavior:** 点击跳转至本地的 `成长地图.html`，带有参数或暗门验证逻辑。

### Section: Main (绘本主封面)
**OBJECT ID:** `cover-main`

- **封面魔法同心圆 SVG**
  - **OBJECT ID:** `cover-main-svg-preview`
  - **Component:** interactive SVG
  - **Details**: 简化版的成功同心圆。圆心为红色“诚信”核心，中环为橙黄“态度”，外环为翠绿“行为”。点击 SVG 触发轻微光环扩散动效（`glow-pulse`）。
- **绘本书名标题组**
  - **OBJECT ID:** `cover-main-title-group`
  - **H1 Content:** "小圆的成长魔法圈"
  - **Sub Content:** "—— 做最好的自己 ——"
- **开始冒险按钮 (Primary CTA)**
  - **OBJECT ID:** `cover-main-button-start`
  - **Component:** large rounded button with gradient fill (`linear-gradient(90deg, #ff7675, #fab1a0)`)
  - **Content:** "开始探险 ➔"
  - **Behavior:** 点击后页面播放“翻页”动画，过渡进入 `01.2-kids-book-story`。

## Technical Notes

- **LocalStorage Integration**:
  - 本页需读取 key: `growmap_unlocked_badges` (已解锁徽章列表数组)，渲染徽章统计。
  - 读取 key: `growmap_checkin_history` (历史打卡记录)。
- **Offline Reliability**: 
  - 所有图标以原生 SVG 行内引入，杜绝因无网导致图像断图。
  - 页面切换使用 CSS 的 `.active` 状态类控制 `display: none / flex` 切换，以单页(SPA)无缝滑入方式实现“翻页”，避免白屏。
